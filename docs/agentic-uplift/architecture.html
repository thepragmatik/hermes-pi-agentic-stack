This is a presentation view. Canonical deterministic representations are architecture.md and architecture.graph.json; routing contracts are routing-mission.schema.json and routing-decision.schema.json.

Text topology

MISSION + durable state
  -> Tier 0 deterministic eligibility/security
  -> Tier 1 multi-label mission profile
  -> Tier 2 bounded workflow/agent selection
  -> Tier 3 model-role/model economic optimization
  -> Tier 4 OpenRouter-first gateway
  -> eligible physical provider / typed Pi stage
  -> evidence + accepted/rejected outcome
  -> offline router research/training

LOCAL_ONLY / impossible capability / unmet ZDR or sandbox requirement exits before cloud.

Boundary rule: research and coding are task families, not the entire ontology. Learned/framework outputs cannot override Tier-0 facts. OpenRouter is a downstream gateway/provider selector, not the privacy boundary. Hermes owns bounded workflow authority; Pi worker provenance is bound to the routing decision; project truth and durable uplift state remain outside model memory.
